# Сервер отсчета дней до Нового года

Микросервис на языке Go, который принимает дату через HTTP-запрос и вычисляет точное количество полных дней, оставшихся до наступления следующего Нового года.

## Назначение приложения
Приложение предоставляет HTTP-интерфейс (API) для автоматического расчета дней до Нового года. Сервис поддерживает два режима работы:
1. Вычисление относительно конкретной даты, переданной пользователем.
2. Вычисление относительно текущей даты на сервере (если дата не указана).

## Требования для запуска
* **Go** версии 1.21 или выше.

## Предоставляемый HTTP API

Сервис предоставляет одну конечную точку для обработки входящих данных.

### Конечная точка (Endpoint)
* **URL:** `/api/newyear`
* **Допустимый HTTP-метод:** `GET`
* **Заголовки ответа:** `Content-Type: application/json`

### Формат входных параметров
Параметры передаются в строке запроса:
* `date` *(опциональный)* - целевая дата в строгом текстовом формате `ДД.ММ.ГГГГ`.
    * *Пример:* `?date=30.12.2026`
    * *Примечание:* Если параметр `date` пуст или отсутствует в запросе, сервер автоматически производит расчет относительно **текущей календарной даты**.

### Формат ответа

#### 1. Успешный сценарий (`200 OK`)
Возвращается при корректном запросе. Тело ответа содержит JSON-объект с количеством дней и обработанной датой:
* `days_left` число дней до Нового года.
* `target_date` дата, от которой производился отсчет.

**Пример запроса:** `GET http://localhost:8080/api/newyear?date=30.12.2026`  
**Ответ сервера:**
```json
{
  "days_left": 2,
  "target_date": "30.12.2026"
}
```

#### 2. Ошибка некорректных параметров (`400 Bad Request`)
Возвращается, если переданная дата имеет неверный формат или содержит недопустимые символы.  
**Пример запроса:** `GET http://localhost:8080/api/newyear?date=67`  
**Ответ сервера:**
```json
{
  "error": "Некорректный формат даты. Используйте ДД.ММ.ГГГГ"
}
```

#### 3. Ошибка недопустимого метода (`405 Method Not Allowed`)
Возвращается при попытке обратиться к API методами `POST`, `PUT`, `DELETE` и др.  
**Пример запроса:** `POST http://localhost:8080/api/newyear`  
**Ответ сервера:**
```json
{
  "error": "Метод не поддерживается"
}
```
